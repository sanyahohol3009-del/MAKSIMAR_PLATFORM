## 1. Purpose

This document records the current limitations of the document-package-rollout pass.

## 2. Current Gap Notes

### Gap 1
The current pass establishes a rollout baseline, not yet a fully executed manifest rollout across all existing packages.

### Gap 2
The pass does not yet replace registry widening, package manifest templates, or structured package-summary implementation.

### Gap 3
Retroactive rollout coverage of older packages is still future work.

### Gap 4
Future deeper work is still needed for:
- actual package rollout execution
- wider package coverage
- stronger package graph semantics
- registry-linked manifest growth
- structured package summaries for future JARVIS

## 3. Final Rule

A package-rollout baseline may begin documentation-first if its remaining gaps are explicit.
