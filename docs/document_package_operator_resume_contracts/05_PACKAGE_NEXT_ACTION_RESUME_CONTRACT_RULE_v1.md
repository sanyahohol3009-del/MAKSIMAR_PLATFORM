# 05 PACKAGE NEXT ACTION RESUME CONTRACT RULE v1

Status: active_canonical
Document Type: canonical
Authority Level: operational
Interpretation Priority: high
Scope: rule for exposing the next operator action through a readable resume contract
Rule: the next action must remain contract-readable so unfinished package work can continue deliberately instead of being rediscovered through rereading and guesswork

---

## 1. Purpose

This document defines the package-next-action-resume-contract rule of the platform.

It exists to preserve:
- readable next-action recovery
- lower ambiguity around what the operator should do next
- continuity between package closure and resumed work
- a stable base for later contract hardening

---

## 2. Next-Action Principle

Next-action resume contracts should remain understandable in terms of:
- what should be done next
- what remains blocked or pending
- what kind of followup is expected
- how next-action contracts preserve continuity

---

## 3. Required Rule

Next-action resume contracts should remain:
- explicit
- selective
- meaningful
- readable
- non-bloated

---

## 4. What Is Forbidden

The following remain forbidden:
- next action rediscovered only by rereading
- next-step handling overloaded with weak or irrelevant details
- next-action meaning preserved only in operator memory
- contracts that hide what still remains to be done

---

## 5. Final Rule

A mature documentation system exposes the next operator action clearly before pauses turn pending work into drift.

---

## 6. Status

This document is the active canonical package-next-action-resume-contract rule until replaced by a stricter action reference.
