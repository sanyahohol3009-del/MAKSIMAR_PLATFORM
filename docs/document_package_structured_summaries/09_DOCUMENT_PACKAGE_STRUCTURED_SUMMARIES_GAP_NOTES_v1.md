## 2. Current Gap Notes

### Gap 1
The current pass establishes package structured-summary baseline semantics, not yet implementation-backed summary tooling.

### Gap 2
The pass does not yet provide automated summary helpers across all package families.

### Gap 3
Full retroactive summary coverage of older packages is still future work.

### Gap 4
Future deeper work is still needed for:
- broader package coverage
- stronger summary and orientation guidance
- summary/registry alignment
- summary diagnostics
- tighter self-reading integration

## 3. Final Rule

A structured-summary baseline may begin documentation-first if its remaining gaps are explicit.
