## 1. Purpose

This document records the current limitations of the document-registry-rollout pass.

It exists to keep the pass honest and bounded.

---

## 2. Current Gap Notes

### Gap 1
The current pass establishes rollout discipline, not yet actual broad package coverage inside `document_registry.yaml`.

### Gap 2
The pass does not yet replace concrete registry editing and verification work.

### Gap 3
Large-scale retrofit of older packages is still future work.

### Gap 4
Future deeper work is still needed for:
- package-by-package registry expansion
- stronger dependency graph capture
- supersession semantics
- wider doc-to-code/test/runbook linkage
- machine-readable package summaries

---

## 3. Final Rule

A rollout baseline may begin as process discipline if its remaining concrete work is explicit.

## 4. Status

This document is the active canonical document-registry-rollout gap note set until replaced by a stricter rollout audit.
