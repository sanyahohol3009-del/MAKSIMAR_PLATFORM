# LONG TERM MEMORY BASELINE v1

Status: active canonical long-term-memory baseline
Scope: persistent continuity-oriented memory structure across the platform
Rule: long-term memory must remain structured, provenance-aware, and bounded so continuity does not become fabricated authority

---

## 1. Purpose

This document defines the long-term-memory baseline of the platform.

It exists to preserve:
- persistent continuity across sessions and project phases
- readable distinction between memory and canonical truth
- bounded long-term recall behavior
- a stable base for later concrete long-term memory families

---

## 2. Long-Term Memory Principle

Long-term memory should remain understandable in terms of:
- continuity preservation over time
- structured storage of meaningful context
- provenance-aware recall
- bounded support for reasoning and project coherence

Long-term memory is not identical to absolute authority.

---

## 3. Memory Intent

Long-term memory should help answer:
- what important continuity should persist
- what source that continuity came from
- what confidence and authority that remembered material carries
- what it may support without replacing canonical truth

---

## 4. Required Rule

Long-term memory thinking should remain:
- explicit
- provenance-aware
- bounded
- continuity-oriented
- consistent with governance and documentation-aware reasoning

---

## 5. What Is Forbidden

The following remain forbidden:
- persistent memory with no provenance awareness
- continuity presented as unquestionable truth
- long-term recall treated as magical authority
- memory growth with no structural discipline

---

## 6. Final Rule

A mature AI platform needs long-term memory that preserves continuity without inflating legitimacy.

---

## 7. Status

This document is the active canonical long-term-memory baseline until replaced by a stricter long-term memory reference.
