# ARCHIVE INGESTION BASELINE v1

Status: active canonical archive-ingestion baseline
Scope: how archived project materials should enter memory-aware continuity surfaces
Rule: archive ingestion must remain structured and provenance-aware so stored history becomes usable continuity rather than indiscriminate memory accumulation

---

## 1. Purpose

This document defines the archive-ingestion baseline of the platform.

It exists to preserve:
- structured intake of prior project materials
- readable continuity from stored historical artifacts
- provenance-aware archive usage
- a stable base for later archive-ingestion workflows and registry-backed archive families

---

## 2. Archive Principle

Archived material should remain understandable in terms of:
- what was preserved
- why it was preserved
- where it came from
- what continuity role it may support
- what authority limits still apply

Archive is not the same as active truth ownership.

---

## 3. Ingestion Intent

Archive ingestion should help answer:
- what historical material is entering the continuity system
- what source class it belongs to
- whether it is canonical, contextual, or interpretive
- how it should be used in later reasoning and recall

---

## 4. Required Rule

Archive-ingestion thinking should remain:
- explicit
- provenance-aware
- continuity-oriented
- bounded
- consistent with long-term memory and documentation-aware reasoning

---

## 5. What Is Forbidden

The following remain forbidden:
- archive dumping with no structure
- historical material treated as automatically current truth
- ingestion with no provenance classification
- continuity built from undifferentiated historical accumulation

---

## 6. Final Rule

A mature AI platform ingests archives deliberately, not by hoarding everything equally.

---

## 7. Status

This document is the active canonical archive-ingestion baseline until replaced by a stricter archive-ingestion reference.
