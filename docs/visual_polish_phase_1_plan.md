# VISUAL POLISH PHASE 1 PLAN v1

Status: active  
Scope: first allowed premium visual polish pass  
Rule: Phase 1 may refine visual language and theme coherence, but may not alter semantics, truth ownership, or runtime meaning

---

## 1. Purpose

This document opens the first allowed visual polish pass after successful completion of the pre-polish package.

Phase 1 exists to improve:

- theme coherence
- visual hierarchy
- panel/frame consistency
- zone readability
- center-core visual gravity
- explainability/sidebar clarity
- status/ticker polish quality

without changing:

- truth ownership
- runtime semantics
- approval semantics
- execution meaning
- control-plane boundaries

---

## 2. Phase 1 Entry Basis

Phase 1 is allowed because the following are already complete:

- visual HUD chain assembled through preview state
- truth/readiness documents created
- visual truth discipline documented
- pre-polish gate documented
- final pre-polish confirmation documented
- tests green

---

## 3. Phase 1 Allowed Work

### 3.1 Theme hardening

Allowed:
- refinement of visual theme tokens
- stronger dark premium HUD consistency
- blue/orange accent discipline
- glass/depth/glow consistency
- consistent border/radius hierarchy

### 3.2 HUD language hardening

Allowed:
- stronger left/center/right zoning
- stronger status bar / ticker coherence
- better panel frame consistency
- stronger separation between foundation / diagnostics / operator / topology surfaces
- more readable visual grouping

### 3.3 Center-core refinement

Allowed:
- stronger center-core emphasis
- cleaner routing/signal readability around the core
- more disciplined depth hierarchy
- better visual gravity in the center region

### 3.4 Sidebar and navigation refinement

Allowed:
- clearer right explainability/security region
- cleaner left navigation region
- stronger active-state readability
- improved operator trust through hierarchy and clarity

---

## 4. Phase 1 Forbidden Work

Phase 1 must not include:

- fake runtime animation
- motion-first redesign
- cinematic FX pass
- semantic UI redesign
- new execution semantics
- new control logic
- new approval semantics
- feature expansion disguised as polish
- multi-display choreography redesign
- advanced interaction redesign

---

## 5. Motion Rule

Motion is not part of mandatory Phase 1 work.

If touched at all, it must remain:
- minimal
- optional
- non-semantic
- non-deceptive

Default rule:
**Phase 1 = mostly static polish first**

## 5.1 Truth Binding Clause

Panel text may be refined visually.
Panel meaning may not be reinterpreted.

Visual emphasis may not imply runtime priority unless such priority already exists in upstream contracts or truth-bound state.

## 5.2 Preview Integrity Clause

Preview must remain traceable to canonical state inputs.

Forbidden:
- fabricated signals
- decorative indicators without source mapping
- preview-only indicators pretending to be runtime truth

## 5.3 Legacy Boundary Clause

Phase 1 does not normalize old naming or old panel ids.

Legacy cleanup is a separate pass.

Polish must not silently convert historical structures, names, or ids.

## 5.4 Test Gate Clause

Any Phase 1 polish change touching:
- render/state mapping
- panel hierarchy
- panel grouping
- panel/view emphasis logic

requires tests to remain green before acceptance.

---

## 6. First Technical Focus

The first technical polish focus after opening Phase 1 should be:

1. visual theme hardening
2. panel/frame hierarchy refinement
3. center-core presentation refinement
4. sidebar/navigation readability refinement
5. ticker/status readability refinement

---

## 7. Acceptance Rule for Phase 1

A Phase 1 change is acceptable only if it:

- improves readability
- improves visual coherence
- improves operator confidence
- preserves truth binding
- preserves read-only visual discipline
- does not introduce semantic ambiguity

---

## 8. Final Rule

Phase 1 polish may make the dashboard feel premium.

It may not make the dashboard less honest.

---

## 9. Status

This document opens the first allowed premium visual polish pass in a constrained, truth-preserving scope.
