## 1. Purpose

This document records the current limitations of the document-package-manifest pass.

It exists to keep the pass honest and bounded.

---

## 2. Current Gap Notes

### Gap 1
The current pass establishes a manifest baseline, not yet a fully implemented manifest system for every documentation package.

### Gap 2
The pass does not yet replace registry rollout, registry hardening, or structured package-summary implementation.

### Gap 3
Retroactive manifest coverage of older packages is still future work.

### Gap 4
Future deeper work is still needed for:
- package manifest templates
- wider manifest coverage
- stronger package graph semantics
- tighter linkage to registry rollout
- structured package summaries for future JARVIS

---

## 3. Final Rule

A package-manifest baseline may begin documentation-first if its remaining gaps are explicit.

---

## 4. Status

This document is the active canonical document-package-manifest gap note set until replaced by a stricter manifest audit.
