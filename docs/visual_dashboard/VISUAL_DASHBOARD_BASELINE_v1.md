# VISUAL DASHBOARD BASELINE v1

Status: active canonical visual/dashboard baseline
Scope: whole-platform visual and dashboard orientation
Rule: the platform must preserve an explicit visual/dashboard baseline so operator-facing visibility remains structured, downstream, and non-authoritative over source truth

---

## 1. Purpose

This document defines the current high-level visual/dashboard baseline of MAKSIMAR/JARVIS.

It exists to preserve:
- operator-facing visibility structure
- dashboard continuity
- downstream presentation discipline
- separation between visibility and authority
- a stable foundation for later visual and renderer-specific documentation

---

## 2. Baseline Principle

Visual/dashboard logic is not merely “UI.”

It also includes:
- what becomes visible to the operator
- how visibility is structured into panels and views
- how downstream presentation relates to runtime and observability truth
- how dashboard semantics stay separate from execution authority
- how display and placement remain subordinate to platform meaning

---

## 3. Core Visual / Dashboard Themes

The platform currently includes or plans for themes such as:

- panel and view semantics
- downstream operator visibility
- dashboard as presentation rather than source of truth
- display and presentation split
- structured visibility of runtime, incidents, and diagnostics
- future renderer and visual shell integration
- explainable operator-facing system state

---

## 4. Required Rule

No meaningful future platform expansion should contradict the need for explicit visual/dashboard discipline.

If a feature damages dashboard clarity or makes presentation act like authority, dashboard discipline wins.

---

## 5. What Is Forbidden

The following remain forbidden:
- dashboard as source of truth
- UI or presentation acting like execution control
- visual surfaces with no semantic structure
- operator visibility existing only as aesthetic output with no system meaning

---

## 6. Final Rule

Visual/dashboard logic is not optional polish.
It is part of the platform’s operator legitimacy.

---

## 7. Status

This document is the active canonical visual/dashboard baseline until replaced by a stricter visual/dashboard reference.
