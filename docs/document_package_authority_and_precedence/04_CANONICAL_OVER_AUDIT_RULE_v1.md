# 04 CANONICAL OVER AUDIT RULE v1

Status: active_canonical
Document Type: canonical
Authority Level: constitutional
Interpretation Priority: strict
Scope: rule establishing canonical package precedence over audit packages
Rule: canonical package meaning must remain stronger than audit closure so closure notes do not silently redefine platform law

---

## 1. Purpose

This document defines the canonical-over-audit rule of the platform.

It exists to preserve:
- readable primacy of canonical material
- lower risk of audit inflation
- continuity between law and closure
- a stable base for later precedence hardening

---

## 2. Rule Principle

Canonical-over-audit precedence should remain understandable in terms of:
- what canonical packages define
- what audit packages summarize
- what audit may clarify without overriding
- how interpretive drift is avoided

---

## 3. Required Rule

Canonical-over-audit precedence should remain:
- explicit
- stable
- readable
- canon-preserving
- governance-aware

---

## 4. What Is Forbidden

The following remain forbidden:
- audit notes silently redefining canonical meaning
- closure treated as stronger than law
- audit inflation through convenience
- precedence inferred only by habit

---

## 5. Final Rule

A mature documentation system keeps closure subordinate to canon.

---

## 6. Status

This document is the active canonical canonical-over-audit rule until replaced by a stricter precedence reference.
