## 1. Purpose

This document records the current limitations of the document-package-traceability-and-linkage pass.

It exists to keep the pass honest and bounded.

---

## 2. Current Gap Notes

### Gap 1
The current pass establishes package traceability and linkage baseline semantics, not yet implementation-backed linkage tooling.

### Gap 2
The pass does not yet provide automated linkage helpers across all package families.

### Gap 3
Full retroactive linkage coverage of older packages is still future work.

### Gap 4
Future deeper work is still needed for:
- broader package coverage
- stronger document and downstream linkage guidance
- package/registry linkage alignment
- linkage diagnostics
- tighter self-reading integration

---

## 3. Final Rule

A traceability baseline may begin documentation-first if its remaining gaps are explicit.
