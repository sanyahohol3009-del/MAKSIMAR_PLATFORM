# Phase 11 Action Library Acceptance v1

Acceptance criteria covered by deterministic contracts and smoke tests:

- JARVIS can select the action worker capability by request intent.
- Verified terminal owner safe browser action is accepted for the Action Library path.
- Unverified voice browser command is denied for direct execution.
- Shell, git, delete, sudo, and CAD/CAM machine control requests stay risk-gated.
- Recording and replay preview are always produced.
- Swarm never executes actions directly; execution stays delegated.
