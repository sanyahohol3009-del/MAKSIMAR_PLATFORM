# MOBILE ACCELERATOR PRODUCT POSITIONING v1

Status: active canonical product positioning note
Scope: ecosystem framing for phone-only, phone+accelerator, and phone+home-node usage
Rule: the accelerator case must be positioned as a capability upgrade, not as a mandatory crutch

---

## 1. Purpose

This document defines the product positioning logic for the mobile accelerator concept.

It exists to keep architecture and product language aligned.

---

## 2. Canonical Product Ladder

### Level 1: Phone Only
Meaning:
- baseline MAKSIMAR mobile node
- local capabilities
- entry-level portability
- no external hardware required

### Level 2: Phone + Accelerator Case
Meaning:
- upgraded mobile compute mode
- improved local/offloaded capability
- still one unified user experience
- external hardware acts as accelerator, not identity source

### Level 3: Phone + Home Node
Meaning:
- heavier workloads route beyond the phone
- phone remains the mobile interface and edge node
- compute scale increases without UX fragmentation

### Level 4: Phone + Home Node + External Modules
Meaning:
- extended compute ecosystem
- specialized modules and future hardware roles
- still one MAKSIMAR/JARVIS experience at UX level

---

## 3. Positioning Principle

The case is not “the one way the app becomes real.”
The case is “one way the platform becomes stronger.”

---

## 4. Strategic Benefit

This model supports:
- modular growth
- differentiated hardware offerings
- progressive user adoption
- clean ecosystem expansion

---

## 5. What Is Forbidden

The following remain forbidden:

- positioning the accelerator as a required fix for a broken base product
- product language that implies the phone-only mode is illegitimate
- backend exposure as UX fragmentation

---

## 6. Final Rule

The base mobile product must stand on its own.
The accelerator case must extend power, not define existence.

---

## 7. Status

This document is the active canonical product positioning note until replaced by a stricter ecosystem/product architecture standard.
