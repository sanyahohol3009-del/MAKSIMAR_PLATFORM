# GOVERNED ACTION BASELINE v1

Status: active canonical governed-action baseline
Scope: legitimacy of action across the platform
Rule: meaningful action must remain governed so the platform does not blur reasoning, proposal, and execution into one unsafe continuum

---

## 1. Purpose

This document defines the governed-action baseline of the platform.

It exists to preserve clarity about:
- when the platform is only reasoning
- when it is proposing
- when it is simulating
- when it is allowed to act
- what makes action legitimate

---

## 2. Baseline Principle

The platform may:
- reason
- propose
- analyze
- simulate
- explain

These do not automatically grant legitimacy to:
- write
- apply
- dispatch
- mutate
- execute real side effects

---

## 3. Required Rule

Meaningful action must remain governed by:
- boundary awareness
- explicit legitimacy conditions
- approval/consent discipline
- protection of sensitive behavior classes

---

## 4. What Is Forbidden

The following remain forbidden:
- hidden action behind “helpful” reasoning
- silent mutation after proposal
- action legitimacy assumed from intelligence alone
- collapsing thought and action into one step

---

## 5. Final Rule

The platform may think broadly.
Action must remain governed.

---

## 6. Status

This document is the active canonical governed-action baseline until replaced by a stricter action-legitimacy specification.
