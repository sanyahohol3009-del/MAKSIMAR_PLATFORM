## 1. Purpose

This document records the current limitations of the security/governance baseline pass.

## 2. Current Gap Notes

The current pass establishes a baseline, not a full threat-model or compliance-family replacement.

### Gap 2
The pass is architecture-oriented, not yet an exhaustive operational security manual.

### Gap 3
Per-subsystem security mappings are still future work.

### Gap 4
Future deeper documentation is still needed for:
- threat model detail
- compliance mapping detail
- operational security runbooks
- per-domain governance specifics

A security/governance baseline may begin high-level if its incompleteness is explicit.
