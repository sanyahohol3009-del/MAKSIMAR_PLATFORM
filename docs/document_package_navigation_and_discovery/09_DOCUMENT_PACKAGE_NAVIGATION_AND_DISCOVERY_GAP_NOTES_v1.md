## 2. Current Gap Notes

### Gap 1
The current pass establishes package navigation-and-discovery baseline semantics, not yet implementation-backed discovery tooling.

### Gap 2
The pass does not yet provide automated discovery helpers across all package families.

### Gap 3
Full retroactive navigation coverage of older packages is still future work.

### Gap 4
Future deeper work is still needed for:
- broader package coverage
- stronger navigation and discovery guidance
- registry and graph-guided discovery alignment
- navigation diagnostics
- tighter self-reading integration

## 3. Final Rule

A navigation baseline may begin documentation-first if its remaining gaps are explicit.
