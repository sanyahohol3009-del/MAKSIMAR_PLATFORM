## 1. Purpose

This document records the current limitations of the visual/dashboard deep pass.

## 2. Current Gap Notes

### Gap 1
The current pass establishes a deeper family baseline, not yet a full renderer-binding or panel-by-panel implementation matrix.

### Gap 2
The pass does not yet replace detailed visual shell, renderer contract, or display-placement procedure documents.

### Gap 3
Per-panel registry entries and per-workspace operational definitions are still future work.

### Gap 4
Future deeper documentation is still needed for:
- panel registry entries
- workspace-specific operator surfaces
- display placement procedures
- renderer/view binding families
- tighter linkage to observability-facing and runtime-facing panels

---

## 3. Required Rule

These notes do not invalidate the baseline.
They show where later hardening is still needed.

## 4. Final Rule

A visual/dashboard deep baseline may begin at family level if its incompleteness is explicit.
