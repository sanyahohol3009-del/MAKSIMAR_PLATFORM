# 07 DOCUMENT DEPENDENCY REFERENCE RULE v1

Status: active_canonical
Document Type: canonical
Authority Level: operational
Interpretation Priority: high
Scope: dependency and cross-reference discipline among documents
Rule: documentation must become graph-like rather than isolated so future JARVIS can navigate meaningfully across related material

---

## 1. Purpose

This document defines the document dependency and reference rule of the platform.

It exists to preserve:
- explicit document relationships
- lower navigation ambiguity
- better package readability
- a stable base for future document-graph behavior

---

## 2. Dependency Principle

Important documents should increasingly declare:
- what they depend on
- what uses them
- what they supersede
- what nearby documents they relate to

A document set should become navigable knowledge, not just a pile of files.

---

## 3. Required Rule

New documents should gradually begin using future-compatible fields such as:
- Depends On
- Used By
- Supersedes

Even if early usage is lightweight, dependency discipline should start now.

---

## 4. What Is Forbidden

The following remain forbidden:
- leaving document relationships entirely implicit forever
- forcing future JARVIS to infer every dependency from raw prose
- growing document count without graph discipline
- creating isolated documents that cannot be placed in the larger system

---

## 5. Final Rule

A mature documentation universe is not only indexed.
It is connected.

---

## 6. Status

This document is the active canonical document dependency and reference rule until replaced by a stricter document-graph standard.
