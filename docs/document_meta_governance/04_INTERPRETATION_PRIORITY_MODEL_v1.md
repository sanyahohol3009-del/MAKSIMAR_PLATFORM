# 04 INTERPRETATION PRIORITY MODEL v1

Status: active_canonical
Document Type: canonical
Authority Level: constitutional
Interpretation Priority: strict
Scope: interpretation-priority levels for future self-reading and human reading of documentation
Rule: document priority must remain explicit so future JARVIS can distinguish binding material from contextual material

---

## 1. Purpose

This document defines the interpretation-priority model of the platform.

It exists to preserve:
- explicit reading priority across document families
- lower risk of history overriding law
- better machine-readable document weighting
- a stable base for future self-reading governance logic

---

## 2. Allowed Priority Values

The current canonical interpretation-priority set is:

- `strict`
- `high`
- `medium`
- `historical`

---

## 3. Priority Meaning

### strict
Highest-priority material. Used for active constitutional rules and hard canonical law.

### high
Strong current guidance. Used for active operational contracts and active canonical layer references.

### medium
Useful current reference, but not stronger than constitutional or operational canon.

### historical
Useful for continuity and explanation, but not for overriding current canonical rules.

---

## 4. Required Rule

New documents should declare interpretation priority explicitly.

Default tendencies:
- constitutional canon -> `strict`
- operational canon -> `high`
- audit closure -> `medium`
- continuity history -> `historical`

---

## 5. What Is Forbidden

The following remain forbidden:
- giving identical reading weight to law and history
- letting continuity notes silently override canonical rules
- omitting interpretation priority on new documents
- inventing undocumented priority meanings ad hoc

---

## 6. Final Rule

A mature self-readable platform knows not only what it remembers, but how strongly to trust each memory.

---

## 7. Status

This document is the active canonical interpretation-priority model until replaced by a stricter document-priority standard.
