# AGENT SWARM OPERATIONS GAP NOTES v1

Status: active canonical agent/swarm operations gap notes
Scope: limitations of the current agent/swarm operations pass
Rule: the agent/swarm operations pass must remain explicit about what is still baseline-level or incomplete

---

## 1. Purpose

This document records the current limitations of the agent/swarm operations pass.

It exists to keep the pass honest and bounded.

---

## 2. Current Gap Notes

### Gap 1
The current pass establishes a baseline, not yet a full swarm operations or agent-registry procedure family.

### Gap 2
The pass does not yet replace detailed coordination, evidence-routing, or approval-aware multi-agent procedures.

### Gap 3
Per-role and per-module operational mappings are still future work.

### Gap 4
Future deeper documentation is still needed for:
- agent registry and role operations families
- coordination and routing procedures
- evidence and approval-aware followup procedures
- tighter linkage to execution policy, mobile, and future physical AI modules

---

## 3. Required Rule

These notes do not invalidate the baseline.
They show where later hardening is still needed.

---

## 4. Final Rule

An agent/swarm operations baseline may begin high-level if its incompleteness is explicit.

---

## 5. Status

This document is the active canonical agent/swarm operations gap note set until replaced by a stricter multi-agent operations audit.
