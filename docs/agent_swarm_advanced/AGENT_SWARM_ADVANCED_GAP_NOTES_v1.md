# AGENT SWARM ADVANCED GAP NOTES v1

Status: active canonical agent/swarm/advanced gap notes
Scope: limitations of the current agent/swarm/advanced baseline pass
Rule: the agent/swarm/advanced pass must remain explicit about what is still baseline-level or incomplete

---

## 1. Purpose

This document records the current limitations of the agent/swarm/advanced baseline pass.

It exists to keep the pass honest and bounded.

---

## 2. Current Gap Notes

### Gap 1
The current pass establishes a baseline, not yet a full agent registry, swarm protocol, or advanced-module governance family.

### Gap 2
The pass does not yet replace detailed coordination, evidence, approval-routing, or multi-agent runbook documents.

### Gap 3
Per-role and per-module operational mappings are still future work.

### Gap 4
Future deeper documentation is still needed for:
- agent registry and role families
- swarm coordination protocol families
- evidence and approval-routing families
- advanced-module lifecycle and placement families
- tighter linkage to execution policy, mobile, and future physical AI modules

---

## 3. Required Rule

These notes do not invalidate the baseline.
They show where later hardening is still needed.

---

## 4. Final Rule

An agent/swarm/advanced baseline may begin high-level if its incompleteness is explicit.

---

## 5. Status

This document is the active canonical agent/swarm/advanced gap note set until replaced by a stricter multi-agent audit.
