# AGENT SWARM ADVANCED BASELINE v1

Status: active canonical agent/swarm/advanced baseline
Scope: whole-platform agent, swarm, and advanced-module orientation
Rule: the platform must preserve an explicit agent/swarm/advanced baseline so multi-agent expansion remains bounded, role-aware, and subordinate to platform governance

---

## 1. Purpose

This document defines the current high-level agent/swarm/advanced baseline of MAKSIMAR/JARVIS.

It exists to preserve:
- continuity of agent and swarm thinking
- bounded role-based expansion
- separation between coordination and authority
- protection against uncontrolled advanced-module sprawl
- a stable foundation for later multi-agent and advanced-module documentation

---

## 2. Baseline Principle

Agent/swarm/advanced logic is not merely “many modules doing things.”

It also includes:
- how agent roles are understood
- how capability boundaries remain explicit
- how swarm coordination stays governed
- how advanced modules remain additions rather than hidden system roots
- how multi-agent expansion remains subordinate to truth, governance, and approval discipline

---

## 3. Core Agent / Swarm / Advanced Themes

The platform currently includes or plans for themes such as:

- role-aware agents
- explicit capability boundaries
- bounded coordination
- governed multi-agent behavior
- evidence-aware and approval-aware advanced execution
- modular advanced expansions that do not redefine the platform root
- future structured collaboration among multiple system components

---

## 4. Required Rule

No meaningful future platform expansion should contradict the need for explicit agent/swarm/advanced discipline.

If a feature causes coordination or advanced modules to overclaim authority, the baseline wins.

---

## 5. What Is Forbidden

The following remain forbidden:
- uncontrolled multi-agent authority
- swarm logic treated as inherently legitimate by scale alone
- advanced modules becoming hidden system roots
- role and capability ambiguity in multi-agent contexts

---

## 6. Final Rule

Agent/swarm/advanced logic is not free-form complexity.
It is a structured extension layer of the platform.

---

## 7. Status

This document is the active canonical agent/swarm/advanced baseline until replaced by a stricter multi-agent reference.
