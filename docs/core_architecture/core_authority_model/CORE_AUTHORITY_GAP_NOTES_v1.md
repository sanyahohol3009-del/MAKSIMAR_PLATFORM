## 1. Purpose

This document records current limitations in the authority-model documentation pass.

## 2. Current Gap Notes

### Gap 1
The current authority model is high-level and conceptual rather than repository-exhaustive.

### Gap 2
Not every subsystem has yet received a fully explicit local authority matrix.

### Gap 3
Future domains such as self-awareness, swarm, and physical AI will require stricter per-domain authority documentation later.

### Gap 4
This pass clarifies architecture semantics, but does not replace future operational governance/runbook detail.

## 4. Final Rule

A high-level authority baseline is acceptable if its incompleteness is visible.
